ℹ️ Sobre el formato ADIF

¿Qué es ADIF?

ADIF (Amateur Data Interchange Format) es el estándar internacional para intercambiar registros de contactos de radioafición. Nuestro log se genera automáticamente en este formato para máxima compatibilidad.

  • ✓ Compatible con QRZ.com, LoTW, eQSL.cc
  • ✓ Importable en Logger32, N1MM, HRD, etc.
  • ✓ Campos incluidos: CALL, QSO_DATE, TIME_ON, FREQ, MODE, RST_SENT, RST_RCVD
  • ✓ Modo reportado: DMR (Digital Mobile Radio)
